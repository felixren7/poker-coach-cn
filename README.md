# 河牌之前 · 德州扑克教练

面向中文新手的无限注德州扑克交互式学习与训练系统。它不是一个“胜率预测器”，也不承诺学完必胜；它把学习闭环做成可运行的产品：

**理解知识 → 查看示范 → 独立决策 → 获得解释 → 针对错误训练 → 在新场景中验证掌握程度**

项目目录原本为空（没有现有代码、README 或 AGENTS.md），因此本版本从零搭建。技术栈优先使用本机已有的 Node.js，采用 **原生 ES Modules + 零运行时依赖 + Node 内置测试**，不需要联网安装依赖，也不需要前端构建步骤。

## 已实现的功能

### 课程与训练

- **5 个阶段、10 节课**：规则 → 翻前 → 翻后 → 概率与多街 → 高阶思考。
- **34 道结构化题目**：牌型比较、最佳五张、合法操作、位置对照、翻前开池/防守/再加注、翻后相对牌力、牌面质地、底池赔率、补牌重叠、结果偏差、范围与阻断牌、转牌/河牌。
- **同类手牌对比**：例如 ATo 在 UTG 与 BTN 的对照、KQ 在干燥面与湿润多人底池的对照。
- 每节课有**可操作示范**，示范不计入练习成绩；独立练习才记录首次表现与提示依赖。
- 三级提示，逐级揭示；提示使用情况进入能力信号。
- 反馈先给结论，再按需展开：当前牌力、对手范围、关键因素、下注尺度、其他合理选择、常见误区、后续计划、策略来源。
- 评分区分四类：规则/计算错误、低于教学基线、合理但存在取舍、符合教学目标。
- 错题按知识标签记录，安排同族变式与间隔复习（1、3、7、14、30 天）。
- 学习进度综合：未见题首次表现、提示独立性、重复错误控制、延迟复测；**不使用虚拟筹码收益或短期胜率**。
- 高阶课程按前置课程逐步解锁，未解锁内容显示原因，不用空白页面冒充已实现。
- 训练题库与每日训练也按已解锁课程过滤；已练过的题始终可复习，避免新用户第一次进入就被高阶术语淹没。

### 牌局与复盘

- 6 人桌、100BB、无前注/无抽水、虚拟筹码的完整模拟牌局。
- 电脑对手是**透明的规则型对手**，三档难度只调整阈值与随机性；只读取公开信息视图，不读取牌堆、未来公共牌或其他玩家暗牌。
- 支持暂停自动行动、保存并返回、查看完整行动记录、下一手与重置。
- 完整结算：主池/边池、短筹码全下、未跟注筹码退回、多人全下自动发完公共牌、平局分池、奇数筹码分配、筹码守恒。
- 每手结束保存初始快照、行动序列与结果；刷新页面可恢复未完成手牌。
- 复盘按街展示行动；关键决策可重做，重做只使用**当时可知信息**，结果信息单独标注为“事后可知”。
- 结局与输赢不用于给决策打分。

### 概率工具箱（第 4 阶段课程内）

- 底池赔率：明确“对手下注前底池 / 对手下注 / 你的跟注 / 跟注后底池”，显示盈亏平衡权益与公式。
- 补牌完成概率：区分翻牌圈两张牌与转牌圈只剩一张；明确“完成概率 ≠ 获胜概率”。
- 范围权益模拟：输入底牌、公共牌、对手范围与模拟次数；展示权益、95% 近似误差、可用范围组合、模拟次数与假设。没有范围假设就不输出“对当前对手的胜率”。

## 默认环境与适用条件

所有策略示例默认：

- 标准 52 张牌、无限注德州扑克；
- 6 人桌；
- 100BB 起始有效筹码；
- 无前注、无抽水、无 straddle；
- 虚拟筹码，不涉及真钱。

这些条件写进了题目的 `source` 或假设说明。**不要直接套用到锦标赛、短筹码、有前注/抽水、单挑或 9 人桌。** 课程与反馈会反复提醒这一点。

内部筹码使用整数（1 枚 = 0.5BB，2 枚 = 1BB），显示时统一换算为 BB，避免浮点误差。界面中的“加注到”指本轮最终总投入，不是额外增加量；面板会同时显示额外投入。

### 分层原则

- **规则引擎不依赖策略/内容/UI**：牌型、行动、边池、结算可以独立测试。
- **策略建议不直接读完整牌桌隐藏信息**：需要公开视图（`getPublicView`）；电脑对手与复盘重做都走这条路径。
- **内容数据化**：题目局面、推荐/可接受答案、解释、提示、来源都在 `src/content/questions.js`，不散落在页面组件里。
- **评分只看题目快照与答案**：不接收最终公共牌、对手暗牌或输赢结果。

## 规则与信息边界

### 规则引擎

已实现并通过测试：

- 9 种牌型排序、最佳五张、踢脚、平局、花色不参与非同一牌型比较；
- A2345（5 高）顺子与 A 高顺子；
- 翻牌前/翻牌后行动顺序、盲注、大盲最后选项；
- 合法过牌/跟注/下注/加注/全下、最小加注；
- 不足额全下不重新开放已行动玩家的加注权；
- 多人全下、主池/边池、分池资格、奇数筹码；
- 未跟注筹码退回、自动发完公共牌、筹码守恒；
- 无重复牌、无负筹码、弃牌玩家不再行动；
- 80 手全桌随机对局 + 200 手开发期模糊测试均保持筹码守恒与状态完整。

### 信息边界

- 策略/电脑对手/复盘重做只读取决策时可知的信息：自己的底牌、公共牌（截至当时）、筹码、位置、行动历史、公开的对手倾向说明。
- 电脑对手通过 `getPublicView` 接收数据；测试会断言视图不含 `deck`、`burned`，其他玩家底牌为 `back`。
- 复盘详情把“结果信息 / 事后暗牌”单独列区，重做面板使用当时的公开快照。
- 不用最终发出的公共牌或单手输赢给决策打分。

## 概率口径

- **补牌完成概率**：例如 9 张同花补牌，翻牌到河牌约 35.0%，转牌到河牌约 19.6%。
- **摊牌权益**：在给定对手范围与发牌假设下的摊牌份额；模拟结果展示模拟次数、范围组合、95% 近似误差与假设。
- **最终赢得底池概率**：还会受到对手弃牌、后续下注与诈唬影响，不能用补牌完成概率或摊牌权益冒充。
- **底池赔率**：跟注额 ÷ 跟注后底池。例：下注前底池 100、对手下注 50、你跟注 50，跟注后底池 200，盈亏平衡权益 25%。
- **重叠补牌去重**：同花 9 + 两头顺 8 − 重叠 2 = 15；不把 15 张补牌说成 15 张必胜牌。
- 还有后续下注时，底池赔率只是当前这一注的必要条件，不是整手牌的最终结论。

## 评分与进度

### 四类判定

| 判定 | 含义 |
| --- | --- |
| 符合教学目标 | 动作/数值符合当前题目的教学基线，且合法 |
| 合理但存在取舍 | 有明确理由的可接受替代，不是错误 |
| 低于教学基线 | 合法但在当前假设下明显较差 |
| 规则/计算错误 | 违反规则，或牌型/概率/数值计算明确错误 |

题目允许推荐答案 + 可接受答案；不是所有偏离默认答案都判错。评分不接收结果信息。

### 能力信号

每个知识标签综合：

1. 未见题首次表现；
2. 提示独立性（提示使用越少越高）；
3. 重复错误控制；
4. 延迟复测（到期后再次作答）。

没有延迟复测时重新分配权重，并明确标注样本不足。模拟筹码输赢、短期胜率、课程完成数量都不直接进入能力信号。

### 间隔复习

- 达标：1 → 3 → 7 → 14 → 30 天逐步拉长；
- 合理取舍：1 天后；
- 低于基线/规则错误：1 天后，并进入错题本；
- 错题复习优先安排到期题、同族变式与薄弱标签。

## 已知限制（如实说明）

1. **不是求解器。** 推荐动作、解释与电脑对手都是简化教学基线；不提供精确 EV 损失、GTO 频率或“唯一最优”。完成课程不代表高手，更不承诺盈利。
2. **电脑对手是规则型。** 三档难度只调整阈值/随机性，不会针对玩家的具体漏洞做高级剥削，也没有完整范围平衡。
3. **固定规则环境。** 只支持 6 人桌、100BB、无前注/无抽水；不支持锦标赛、短筹码、单挑、9 人桌、straddle 或真钱抽水模型。
4. **题目覆盖仍可扩展。** 第一批 34 题覆盖规则、翻前、翻后、概率、范围与部分转牌/河牌；更系统的转牌/河牌专项、多人全下专题、深筹码专题仍可作为下一批内容。模拟牌局和复盘本身覆盖完整四条街。
5. **策略基线存在边界。** 教练对某些边缘局面的判断可能比结构化题目的推荐更保守或更激进；界面标注“教学基线”，不把它包装成 solver 结论。
6. **数据只在本地。** 没有账号、云同步或后端题库管理；导出/导入是人工备份。
7. **可访问性未做全面审计。** 已有键盘焦点样式、语义标签、非仅颜色区分花色、响应式布局；但未做完整屏幕阅读器/无障碍认证。
8. **动画与声音很少。** 优先保证教学清晰与操作顺畅；`settings.sound` 目前没有接入音频。
9. **概率工具是范围假设工具。** 权益模拟依赖你输入的对手范围，不是读牌；不输出最终赢池概率或 EV 决策。
10. **浏览器兼容性。** 目标是现代 Chrome/Safari/Edge；依赖原生 ES Modules 与 `localStorage`。

## 后续优先级

1. **题库扩展**：转牌/河牌下注尺度、多人底池、短筹码全下、ICM/锦标赛专题（需要显式新环境假设）；每个新题继续由内容测试验证合法性。

3. **更丰富的电脑对手**：按玩家倾向调整、位置相关的翻后策略、可复现的难度参数；继续保证公开信息边界。
4. **复盘增强**：多街计划评分、范围假设对比、可导出复盘报告。
5. **无障碍与移动端**：完整键盘导航、屏幕阅读器检查、字号/对比度设置；移动端行动面板已固定，但可继续做手势与安全区适配。

7. **求解器接入（高阶）**：只有接入可靠求解器或经过审计的模拟后，才展示精确频率/EV；在此之前保持“教学基线”的边界。
